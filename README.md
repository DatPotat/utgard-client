# Utgard

Utgard — приложение для маршрутизации выбранных сайтов и программ через VPN. Через VPN идёт только то, что вы выбрали, остальной трафик — напрямую.

> **Важно:** Utgard не является VPN-сервисом и не предоставляет VPN-серверы. Нужен профиль или ссылка от вашего VPN-провайдера или владельца сервера.

## Что умеет Utgard

- направлять через VPN выбранные сайты и выбранные программы;
- работать с профилями VLESS, VMess, Trojan, Shadowsocks, Hysteria2, WireGuard и AmneziaWG — по ссылке, из подписки или из файла конфигурации;
- принимать ключи Amnezia `vpn://`;
- переключать профиль на лету, с проверкой нового профиля и возвратом к прежнему, если новый не запустился;
- работать вместе с `zapret`;
- запускаться вместе с Windows и работать из области уведомлений.

Utgard — **portable-приложение**: его не нужно устанавливать, рабочие файлы создаются в папке программы.

## Требования

- Windows 10 или Windows 11, **x64 или ARM64** — для каждой архитектуры свой архив;
- права администратора;
- для профилей AmneziaWG — папка программы на диске **NTFS** (на FAT32 и exFAT они недоступны);
- VPN-профиль или ссылка на подписку.

IPv6 Utgard не использует: туннели работают только по IPv4.

## Быстрый старт

1. **Скачайте архив** для своей архитектуры со [страницы релизов](https://github.com/DatPotat/utgard-client/releases/latest) и полностью распакуйте в отдельную папку, например `C:\Program Files\Utgard\`. Запускать `utgard.exe` из архива не следует.
2. **Запустите `utgard.exe`.** Windows запросит права администратора. При первом запуске Utgard предложит скачать ядро **sing-box**, затем — ядро **AmneziaWG** (нужно только для профилей AmneziaWG, от него можно отказаться).
3. **Добавьте профиль:** «Добавить профиль…» → «Вставить ссылку…» или «Файл WireGuard / AmneziaWG (.conf)…». Для подписки — кнопка «Подписка…».
4. **Выберите, что пускать через VPN:** «Список сайтов…» и/или «Приложения…». Без хотя бы одного сайта или приложения VPN не включится.
5. **Нажмите «Включить».** Пока VPN работает, кнопка красная и называется «Выключить».

## Профили

**Ссылки:** `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`, `wireguard://`, а также ключи Amnezia `vpn://`.

**Файлы:** конфигурация WireGuard или AmneziaWG (`.conf`) либо текстовый файл с одной ссылкой.

**Подписки:** только по `https://`, обновляются автоматически по расписанию из настроек.

Для **AmneziaWG** поддерживаются параметры всех поколений протокола — 1.x, 2.0 и 3.x (`Jc`, `Jmin`, `Jmax`, `S1–S4`, `H1–H4`, `I1–I5`, `HeaderProtectionKey`, диапазоны таймингов и `PersistentKeepalive`). Некорректные параметры отклоняются при добавлении с объяснением — например, пересекающиеся `H1–H4`.

**Ключи Amnezia `vpn://`** принимаются в любом виде, который понимает клиент Amnezia: сжатые и несжатые, с префиксом `vpn://` и без него, с полным конфигом сервера или с конфигурацией WireGuard/AmneziaWG внутри. Из ключа берётся профиль AmneziaWG или WireGuard. Не принимаются:
- ключи сервисов Amnezia Premium и Free — они работают только через шлюз Amnezia;
- ключи полного доступа к серверу — в них нет настроек подключения;
- ключи, где есть только Xray, OpenVPN и другие протоколы.

**Не поддерживаются:** транспорты `xhttp` и `kcp` и VLESS с собственным шифрованием Xray (`encryption`) — ядро sing-box их не умеет.

**Выбор профиля** — двойной щелчок в списке. Если VPN включён, Utgard сначала проверяет конфигурацию нового профиля и возможность вернуться к текущему, затем переключается. Если новый профиль не запустился, возвращается прежний, и строка состояния сообщает об этом. Пока идёт переключение, щелчки по профилям и кнопки подписки не действуют.

**Задержка до сервера** — кнопка «ping до сервера». Для WireGuard и AmneziaWG она измеряется по ICMP, который многие серверы не пропускают: «ICMP не отвечает» не значит, что туннель не работает.

## Маршрутизация сайтов

Впишите домены по одному в строке, например `example.com`. Поддомены учитываются автоматически. Кнопка «Убрать дубли» удаляет повторы и поддомены, уже покрытые родительским доменом; «Сохранить» сохраняет список и собирает его для sing-box.

Если сайт не открывается, в список может понадобиться добавить и его вспомогательные домены — изображений, API, авторизации.

## Маршрутизация программ

В окне «Приложения…» можно выбрать программу из запущенных процессов (поиск по имени и PID), задать имя процесса или путь вручную, включать и выключать наборы правил. Если программа состоит из нескольких процессов, добавьте все нужные.

Набор правил — JSON-файл в `list\applications\active\`. Помимо правил маршрутизации (`route.rules`) он может задавать DNS-серверы и правила DNS (`dns.servers`, `dns.rules`). DNS-серверы в таком файле допускаются только типов `local`, `tcp`, `udp`, `tls`, `quic`, `https`, `h3`; пути к файлам в их настройках TLS не используются. Файлы из `list\applications\inactive\` не применяются.

## AmneziaWG

Для профилей AmneziaWG используется официальное ядро **AmneziaWG для Windows**. Utgard скачивает официальный пакет, сверяет его контрольную сумму и берёт из него `amneziawg.exe` и `wintun.dll` — в систему ничего не устанавливается.

Пока включён AmneziaWG-профиль:
- работает служба Windows `AmneziaWGTunnel$utgard-awg-tun`, и есть сетевой адаптер `utgard-awg-tun`;
- sing-box направляет в этот адаптер только выбранные сайты и программы, остальное идёт напрямую;
- конфигурация туннеля передаётся службе напрямую, минуя диск.

При выключении служба и адаптер удаляются. Новое подключение создаётся только после того, как адаптеры предыдущего действительно исчезли из системы; строка состояния показывает «Ожидание удаления старого соединения…».

## Работа вместе с zapret

Если вы не используете `zapret`, этот раздел можно пропустить.

Поддерживается сборка [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — папка с `service.bat` и `bin\winws.exe`. На вкладке **zapret** доступно:
- выбор стратегии и управление службой: «Запустить», «Перезапустить», «Выключить»;
- переключатели **Game filter** и **IPSet filter**, обновление списка IPSet;
- проверка файла `hosts`: Utgard скачивает актуальный файл и, если он отличается от системного, открывает оба. Системный `hosts` Utgard не изменяет;
- редактирование пользовательского списка хостов zapret.

Кнопка **«Исправить конфликт VPN и zapret»** добавляет адреса ваших VPN-серверов в исключения zapret, чтобы zapret не мешал соединению с ними.

## Во время работы

- **Область уведомлений:** значок показывает состояние VPN; меню позволяет открыть окно, включить или выключить VPN и выйти.
- **Закрытие окна:** при включённой настройке «Сворачивать в трей при закрытии» окно прячется, иначе программа закрывается.
- **VPN продолжает работать** и после закрытия окна, и после выхода из программы. При следующем запуске Utgard определит, что VPN включён.
- **Строка состояния** показывает, что происходит: «Проверка конфигурации…», «Включение туннеля AmneziaWG…», «Включение VPN…», «Выключение VPN…» и т. д.
- Если туннель AmneziaWG пропал, пока VPN включён, строка состояния сообщает об этом.

## Настройки

- **MTU** — от 1280 до 9000;
- **Журнал** — уровень подробности журнала sing-box;
- **Стек** — сетевой стек туннеля: `system`, `gvisor` или `mixed`;
- **DNS** — DNS поверх HTTP/3 для сайтов из списка: Google, Cloudflare или Quad9;
- **Подписка** — период автообновления;
- **Сворачивать в трей при закрытии**;
- **Запускать вместе с Windows (свёрнутым в трей)**;
- **Проверять обновления при запуске** и кнопка «Проверить обновления»;
- **Используемые версии** Utgard, sing-box и AmneziaWG — каждая ссылкой на страницу своего релиза.

Изменения туннеля вступают в силу со следующего включения VPN.

**Запуск вместе с Windows** создаёт задачу в Планировщике заданий Windows. Программа стартует свёрнутой при входе пользователя, без запроса UAC; VPN при этом не включается.

> **Безопасность:** с автозапуском Utgard получает права администратора без подтверждения. Держите программу в папке, куда пишут только администраторы, например в `C:\Program Files\Utgard\`.

## Файлы и приватность

В папке программы:

- `profiles.dat` — профили, зашифрованные средствами Windows (DPAPI) и привязанные к учётной записи. Если файл не удаётся прочитать (другая учётная запись или компьютер), Utgard не перезаписывает его, а переименовывает в `profiles.dat.unreadable-<дата-время>`;
- `config.json` — базовая конфигурация sing-box для ручной настройки; Utgard создаёт её, если файла нет, и больше не изменяет;
- `settings.txt`, `zapret-path.txt` — настройки;
- `sing-box\` и `amneziawg\` — ядра. Писать в эти папки могут только администраторы; перед каждым запуском Utgard сверяет их содержимое с официальными контрольными суммами и не запускает ядро, если в папке лишний или изменённый файл;
- `list\` — список сайтов, наборы правил для программ, скачанный для проверки файл `hosts`;
- `logs\sing-box.log` — журнал sing-box.

Конфигурация, с которой работают sing-box и AmneziaWG, собирается в памяти и передаётся им напрямую: ключи и пароли серверов открытым текстом на диск не попадают.

Вне папки программы Utgard:
- создаёт задачу в Планировщике заданий — только если включён запуск вместе с Windows;
- устанавливает службу zapret и изменяет файлы в папке zapret — только по вашим действиям на вкладке zapret;
- на время сеанса AmneziaWG создаёт службу и сетевой адаптер (см. «AmneziaWG»). Служба AmneziaWG ведёт журнал в `C:\Program Files\AmneziaWG\Data`; Utgard удаляет эту папку после выключения, если создал её сам и если у вас не установлен собственный клиент AmneziaWG.

## Сетевые обращения

Utgard не собирает телеметрию, не имеет аккаунтов и собственных серверов. Сама программа обращается в сеть только в этих случаях:

| Куда | Когда | Зачем |
|---|---|---|
| `github.com` | при запуске (отключается в настройках) и по кнопке «Проверить обновления» | узнать номер последней версии Utgard |
| `github.com` | после вашего согласия | скачать sing-box и ядро AmneziaWG |
| адрес вашей подписки | при добавлении подписки и при её автообновлении | получить профили |
| ваши VPN-серверы | при запуске, при изменении списка профилей и по кнопке «ping до сервера» | измерить задержку (TCP; для Hysteria2, WireGuard и AmneziaWG — ICMP) |
| системный DNS | перед включением AmneziaWG-профиля; если указана папка zapret — при проверке исключений | узнать IP-адреса ваших серверов |
| `raw.githubusercontent.com` (репозиторий Flowseal/zapret-discord-youtube) | только по кнопкам обновления IPSet и проверки `hosts` | получить актуальные списки zapret |

Запросы к GitHub и к адресу подписки отправляются с заголовком `User-Agent: utgard/1.0`: получатель видит ваш IP-адрес и то, что запрос сделан Utgard.

Когда VPN включён, соединения устанавливают sing-box и, для AmneziaWG-профилей, служба AmneziaWG: к вашим VPN-серверам и к выбранному DNS поверх HTTP/3 — для имён сайтов из списка.

## Сборка из исходников

Нужен mingw-w64 для x64 и llvm-mingw для arm64 (Linux, MSYS2 или Git Bash с w64devkit).

```sh
./build.sh              # обе архитектуры: bin/x64/ и bin/arm64/
ARCH=x64 ./build.sh     # только одна
sh tests/run.sh         # тесты переносимой части (gcc, AddressSanitizer)
```

Каждая папка в `bin/` — готовый комплект для своего архива: `utgard.exe` и `licenses\`. Версия программы задаётся в одном месте — `src/version.h`.

## Лицензия

Utgard Client распространяется под лицензией **MIT** (`licenses\UTGARD-MIT.txt`).

Сторонние компоненты (подробно — `licenses\THIRD-PARTY-NOTICES.txt`):
- **Parson** (MIT) и **puff** из zlib (лицензия zlib) встроены в `utgard.exe`;
- **sing-box** (GPL-3.0-or-later) скачивается из официального релиза и работает отдельной программой; файл лицензии из официального архива лежит рядом с `sing-box.exe`. Исходный код — https://github.com/SagerNet/sing-box;
- **AmneziaWG для Windows** (MIT) скачивается из официального релиза и работает отдельной программой; исходный код — https://github.com/amnezia-vpn/amneziawg-windows-client;
- **Wintun** (лицензия Prebuilt Binaries License WireGuard LLC) приходит в пакете AmneziaWG и используется без изменений.

## Отказ от гарантий

Utgard предоставляется «как есть», без гарантий. Пользователь самостоятельно отвечает за законность использования VPN, маршрутизации трафика и других сетевых инструментов в своей юрисдикции.
