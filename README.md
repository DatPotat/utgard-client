# Utgard v2.0.3

Utgard — приложение для маршрутизации выбранных сайтов и программ через VPN.

Вместо того чтобы отправлять через VPN весь интернет, Utgard позволяет выбрать, **что именно** должно идти через VPN, а остальной трафик отправлять напрямую.

Utgard работает на **Windows 10 и Windows 11 (x64)**.

> **Важно:** Utgard не является VPN-сервисом и не предоставляет VPN-серверы. Для работы нужен VPN-профиль или ссылка от вашего VPN-провайдера или владельца сервера.

## Что умеет Utgard

- направлять выбранные сайты и адреса через VPN;
- направлять выбранные программы через VPN;
- работать с профилями VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и WireGuard — по ссылкам, из подписки или из файла WireGuard `.conf`;
- работать вместе с `zapret`;
- загружать ядро `sing-box` при первом запуске;
- запускаться вместе с Windows (по желанию) и работать из области уведомлений.

Utgard — **portable-приложение**: его не нужно устанавливать. Рабочие файлы создаются в папке программы.

## Быстрый старт

### 1. Распакуйте Utgard

Скачайте архив со [страницы релизов](https://github.com/DatPotat/utgard-client/releases/latest) и полностью распакуйте его в отдельную папку, например:

```text
C:\Program Files\Utgard\
```

Запускать `utgard.exe` непосредственно из архива не следует: программа создаёт рабочие файлы рядом с собой.

### 2. Запустите `utgard.exe`

Utgard требует права администратора для работы с сетевой маршрутизацией, поэтому Windows запросит подтверждение.

При первом запуске Utgard предложит скачать `sing-box` **1.14.1**. Работает только эта версия: перед каждым запуском Utgard сверяет файлы `sing-box` с контрольными суммами официального релиза и не запускает другие. Если скачать автоматически нельзя, распакуйте официальный архив `sing-box-1.14.1-windows-amd64.zip` в папку `sing-box` рядом с `utgard.exe`.

### 3. Добавьте VPN-профиль

Нажмите **«Добавить профиль…»** и выберите:

- **«Вставить ссылку…»** — для ссылок `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`, `wireguard://`;
- **«Файл WireGuard (.conf)…»** — для файла конфигурации WireGuard.

Если у вас ссылка подписки, нажмите **«Подписка…»**: Utgard получит из неё профили и будет обновлять их автоматически. Подписка принимается только по `https://`.

Чтобы выбрать профиль, дважды щёлкните по нему в списке.

Не поддерживаются ссылки с транспортами `xhttp` и `kcp`, а также VLESS с собственным шифрованием Xray (`encryption`): ядро `sing-box` их не умеет. Utgard сообщит об этом при добавлении.

### 4. Выберите, что отправлять через VPN

- **сайты и адреса** — кнопка **«Список сайтов…»**;
- **программы** — кнопка **«Приложения…»**.

Список сайтов нужно сохранить хотя бы один раз: без него VPN не включится.

### 5. Включите VPN

Нажмите **«Включить»**. Пока VPN работает, кнопка становится красной и называется **«Выключить»**.

Выбранный трафик идёт через VPN, остальной — напрямую.

## Маршрутизация сайтов

Впишите нужные домены по одному в строке, например:

```text
example.com
```

Поддомены учитываются автоматически. Кнопка **«Убрать дубли»** удаляет повторы и поддомены, уже покрытые родительским доменом. Кнопка **«Сохранить»** сохраняет список и собирает его для `sing-box`.

Если сайт не открывается, это не обязательно означает проблему с VPN. Современные сайты используют несколько доменов — для изображений, API, авторизации. В таком случае в список нужно добавить и их.

## Маршрутизация программ

Utgard может направлять через VPN весь трафик выбранной программы. Это удобно для приложений и игр, которые используют много разных адресов.

В окне **«Приложения…»** можно:

- выбрать программу из запущенных процессов (с поиском по имени и PID);
- задать имя процесса или путь к нему вручную;
- включать и выключать наборы правил, не удаляя их.

Некоторые программы состоят из нескольких процессов: лаунчер, клиент, служба обновления. Если через VPN должен идти весь комплект, добавьте все нужные процессы.

Для расширенной настройки набор правил — это JSON-файл в папке `list\applications\active\`. Помимо правил маршрутизации (`route.rules`) он может содержать собственные DNS-серверы и правила DNS (`dns.servers`, `dns.rules`). Файлы из `list\applications\inactive\` не применяются.

## Работа вместе с zapret

Если вы не используете `zapret`, этот раздел можно пропустить.

Utgard поддерживает сборку [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — папку, в которой есть `service.bat` и `bin\winws.exe`. После выбора папки на вкладке **zapret** доступно:

- выбор стратегии и управление службой zapret: **«Запустить»**, **«Перезапустить»**, **«Выключить»**;
- переключатели **Game filter** и **IPSet filter**;
- обновление списка IPSet;
- проверка файла `hosts`: Utgard скачивает актуальный файл из репозитория, сравнивает с системным и, если они различаются, открывает оба. Системный `hosts` Utgard не изменяет;
- редактирование пользовательского списка хостов zapret (`lists\list-general-user.txt`).

При одновременной работе zapret может вмешиваться в соединение с VPN-сервером. Кнопка **«Исправить конфликт VPN и zapret»** добавляет адреса ваших VPN-серверов в исключения zapret (`lists\ipset-exclude-user.txt`, с резервной копией). zapret подхватывает изменённые списки сам, без перезапуска. Если VPN в этот момент включён, его стоит переподключить: уже открытые соединения сохраняют прежние правила.

## Во время работы

**Область уведомлений.** Значок показывает состояние VPN. Меню значка позволяет открыть окно, включить или выключить VPN и выйти из программы.

**Закрытие окна.** Если в настройках включено «Сворачивать в трей при закрытии», крестик прячет окно в область уведомлений. Иначе программа закрывается.

**VPN продолжает работать** и после закрытия окна, и после выхода из программы. Чтобы его остановить, нажмите **«Выключить»** в окне или в меню значка. При повторном запуске Utgard определит, что VPN уже работает.

**Выключение.** Utgard просит `sing-box` завершиться штатно и ждёт до 12 секунд, пока тот освободит сетевой адаптер. Кнопка остаётся неактивной до завершения. Если `sing-box` пришлось остановить принудительно, Utgard сообщит об этом.

**Если `sing-box` остановится сам** (например, из-за ошибки), индикатор переключится на «VPN выключен», а трафик пойдёт напрямую, без VPN.

## Настройки

Изменения туннеля вступают в силу со следующего включения VPN.

- **MTU** — от 1280 до 9000, по умолчанию 1430;
- **Журнал** — уровень подробности журнала `sing-box`, по умолчанию `warn`;
- **Стек** — сетевой стек туннеля: `system`, `gvisor` или `mixed`;
- **DNS** — DNS поверх HTTP/3 для сайтов из списка: Google, Cloudflare или Quad9;
- **Подписка** — автообновление каждые 3, 6 или 12 часов;
- **Сворачивать в трей при закрытии**;
- **Запускать вместе с Windows (свёрнутым в трей)**;
- **Проверять обновления при запуске** и кнопка **«Проверить обновления»**.

### Запуск вместе с Windows

Utgard создаёт задачу в Планировщике заданий Windows: `Utgard (<идентификатор пользователя>)`. Задача запускает программу свёрнутой при входе вашего пользователя, без запроса UAC, в том числе при работе от батареи. VPN при этом не включается — только сама программа.

Если перенести папку Utgard, галочка снимется: включите её снова, и задача укажет на новое место.

> **Безопасность:** с автозапуском Utgard получает права администратора без подтверждения. Если папку с программой могут изменять другие пользователи или программы без прав администратора, подмена файлов в ней даст им эти права. Поэтому для автозапуска держите Utgard в папке, куда пишут только администраторы, например в `C:\Program Files\Utgard\`.

## Файлы и приватность

Что хранится в папке программы:

- `profiles.dat` — профили VPN. Файл зашифрован средствами Windows (DPAPI) и привязан к вашей учётной записи: на другом компьютере или под другим пользователем профили не прочитаются. В этом случае Utgard не перезаписывает файл, а переименовывает его в `profiles.dat.unreadable-<дата-время>` и начинает список заново;
- `settings.txt` — настройки программы;
- `zapret-path.txt` — путь к папке zapret;
- `sing-box\` — `sing-box.exe`, `libcronet.dll` и `LICENSE` из официального архива;
- `sing-box\config.json` — базовая конфигурация. Utgard создаёт её, если файла нет, и больше не изменяет: это файл для ручной настройки. Значения из окна настроек перекрывают его;
- `sing-box\config.generated.json` — конфигурация, собранная для `sing-box`. Данные серверов в ней хранятся **открытым текстом**;
- `list\hosts` — список сайтов; `list\general.srs` — он же, собранный для `sing-box`;
- `list\applications\` — наборы правил для программ;
- `logs\sing-box.log` — журнал `sing-box`.

Не передавайте другим людям всю рабочую папку без проверки: в ней могут быть конфигурации с данными серверов и журналы. Перед публикацией копии проверьте `sing-box\config.generated.json`, `sing-box\config.json` и `logs\`.

Вне папки программы Utgard:

- создаёт задачу в Планировщике заданий — только если включён запуск вместе с Windows;
- устанавливает службу zapret и изменяет файлы в папке zapret — только по вашим действиям на вкладке zapret;
- использует временную папку Windows при загрузке `sing-box` и проверке файла `hosts`.

## Приватность и сетевые обращения

Utgard не собирает телеметрию и статистику использования, не имеет аккаунтов и собственных серверов. Профили, подписки и списки никуда не передаются.

Сама программа обращается в сеть только в следующих случаях:

| Куда | Когда | Зачем |
|---|---|---|
| `github.com` | при запуске (отключается в настройках) и по кнопке «Проверить обновления» | узнать номер последней версии Utgard |
| `github.com` | при первом запуске, после вашего согласия | скачать sing-box 1.14.1 |
| адрес вашей подписки | при добавлении подписки и при её автообновлении | получить профили |
| ваши VPN-серверы | при запуске, при изменении списка профилей и по кнопке «ping до сервера» | измерить задержку (TCP-подключение; для Hysteria2 и WireGuard — ICMP) |
| системный DNS | если указана папка zapret: при запуске, при изменении профилей и по кнопке «Исправить конфликт VPN и zapret» | узнать IP-адреса ваших серверов, чтобы проверить исключения zapret |
| `raw.githubusercontent.com` (репозиторий Flowseal/zapret-discord-youtube) | только по кнопкам обновления IPSet и проверки hosts на вкладке zapret | получить актуальные списки zapret |

Запросы к GitHub и к адресу подписки отправляются с заголовком `User-Agent: utgard/1.0`: получатель видит ваш IP-адрес и то, что запрос сделан Utgard.

Когда VPN включён, сетевые соединения устанавливает `sing-box`: к вашим VPN-серверам и к выбранному в настройках DNS поверх HTTP/3 (Google, Cloudflare или Quad9) — для имён сайтов из списка. Остальные имена разрешаются системным DNS.

## Требования

- Windows 10 x64 или Windows 11 x64;
- права администратора;
- VPN-профиль или ссылка на подписку.

Дополнительный VPN-клиент устанавливать не требуется.

## Лицензия

Utgard Client распространяется под лицензией **MIT**. Полный текст — в файле `LICENSE`.

### Сторонние компоненты

В `utgard.exe` встроена библиотека **Parson 1.5.4** для работы с JSON (лицензия **MIT**). Её исходный код находится в `vendor/parson/`; в `parson.c` и `parson.h` сохранено оригинальное уведомление об авторских правах, которое при распространении исходного кода необходимо сохранять.

Тексты лицензий распространяются вместе с программой в папке `licenses\`: лицензия Utgard, лицензия Parson и перечень сторонних компонентов.

Utgard использует `sing-box 1.14.1` (лицензия **GPL-3.0-or-later**). `sing-box` не входит в архив Utgard: программа скачивает официальный релиз с GitHub и запускает его как отдельную программу, не встраивая в `utgard.exe`. Файл лицензии из официального архива распаковывается рядом с `sing-box.exe`. Исходный код: https://github.com/SagerNet/sing-box/tree/v1.14.1

## Отказ от гарантий

Utgard предоставляется «как есть», без гарантий.

Пользователь самостоятельно отвечает за законность использования VPN, маршрутизации трафика и других сетевых инструментов в своей юрисдикции.
