# Utgard v2.0.0

Utgard — приложение для маршрутизации выбранных сайтов и программ через VPN.

Вместо того чтобы отправлять через VPN весь интернет, Utgard позволяет выбрать, **что именно** должно идти через VPN, а остальной трафик отправлять напрямую.

Utgard работает на **Windows 10 и Windows 11 (x64)**.

> **Важно:** Utgard не является VPN-сервисом и не предоставляет VPN-серверы. Для работы нужен VPN-профиль или конфигурационная ссылка от вашего VPN-провайдера или владельца сервера.

## Что умеет Utgard

- направлять выбранные сайты и адреса через VPN;
- направлять выбранные программы через VPN;
- работать с ссылками конфигурации и ссылками профилей;
- работать вместе с `zapret`;
- автоматически загружать необходимое ядро при первом запуске;
- хранить рабочие файлы рядом с `Utgard.exe`.

Utgard — **portable-приложение**: его не нужно устанавливать. Оно не добавляется в автозагрузку и не создаёт отдельную установку в Windows. Рабочие файлы создаются в каталоге программы.

## Быстрый старт

### 1. Распакуйте Utgard

Скачайте архив с Utgard и полностью распакуйте его в отдельную папку.

Рекомендуется использовать путь без кириллицы и других необычных символов, например:

```text
C:\Programs\Utgard\
```

Запускать `Utgard.exe` непосредственно из архива не следует.

### 2. Запустите `Utgard.exe`

Utgard требует права администратора для работы с сетевой маршрутизацией, поэтому Windows запросит подтверждение запуска от имени администратора.

При первом запуске необходимые файлы `sing-box` будут загружены автоматически. Если загрузка невозможна, их можно добавить вручную в папку `sing-box`.

Для версии Utgard v2.0.0 используется `sing-box` **1.14.1**.

### 3. Добавьте VPN-профиль

Для работы нужен VPN-профиль или ссылка на конфигурацию.

Добавьте полученную от VPN-провайдера или владельца сервера ссылку в разделе профилей. Если используется ссылка подписки, Utgard может получить из неё профили и обновлять их.

### 4. Выберите, что отправлять через VPN

Utgard позволяет выбрать:

- **сайты и адреса** — через список хостов;
- **программы** — через правила для приложений.

Если программа использует много разных доменов, маршрутизация по приложению обычно удобнее списка сайтов.

### 5. Включите Utgard

Выберите нужный профиль и включите маршрутизацию.

После этого выбранный трафик будет идти через VPN, а остальной — напрямую.

## Маршрутизация сайтов

Добавьте нужные домены в список маршрутизации, по одному адресу в строке.

Например:

```text
example.com
```

Поддомены учитываются автоматически, поэтому обычно нет необходимости добавлять каждый поддомен отдельно.

Если сайт не открывается, это не обязательно означает проблему с VPN. Современные сайты могут использовать несколько доменов для самого сайта, изображений, API, авторизации и других сервисов. В таком случае в список может потребоваться добавить дополнительные адреса.

## Маршрутизация программ

Utgard может направлять через VPN трафик выбранной программы целиком.

Это особенно удобно для приложений и игр, которые используют много разных адресов.

Некоторые программы состоят из нескольких процессов. Например, у игры могут отдельно работать лаунчер, основной клиент, служба обновления или другие компоненты. Если через VPN должен работать весь такой комплект, необходимо учитывать все нужные процессы.

Более подробная настройка правил для приложений относится к расширенному использованию и не требуется для обычного запуска Utgard.

## Работа вместе с zapret

Utgard может использоваться вместе с `zapret`.

`zapret` — отдельный инструмент, который может применяться для обхода блокировок и модификации сетевого трафика на компьютере.

При одновременной работе `zapret` и Utgard могут возникать конфликты: модификация трафика может вмешиваться в соединение с VPN-шлюзом.

Utgard умеет определить адреса VPN и помочь добавить их в исключения `zapret`.

Если вы не используете `zapret`, этот раздел можно пропустить.

## После запуска

Окно Utgard можно закрыть — запущенная маршрутизация продолжит работать.

Чтобы остановить маршрутизацию, используйте кнопку или команду остановки в приложении.

Utgard не добавляется в автозагрузку Windows. После перезагрузки компьютера приложение нужно запустить снова вручную.

## Файлы и приватность

Utgard является portable-приложением. Необходимые для его работы файлы создаются рядом с `Utgard.exe`.

Не передавайте другим людям всю рабочую папку без проверки её содержимого. В ней могут находиться сохранённые VPN-профили, конфигурации и журналы работы программы.

В частности, перед публикацией или передачей копии проверьте файлы конфигурации и каталог `logs\`.

Что хранится в папке программы:

- `profiles.dat` — профили VPN. Файл зашифрован средствами Windows (DPAPI) и привязан к вашей учётной записи: на другом компьютере или под другим пользователем профили не прочитаются, их нужно будет добавить заново;
- `sing-box\config.generated.json` — конфигурация, собранная для sing-box. Данные серверов в ней хранятся **открытым текстом**;
- `logs\sing-box.log` — журнал sing-box;
- `settings.txt` — настройки программы.

## Приватность и сетевые обращения

Utgard не собирает телеметрию и статистику использования, не имеет аккаунтов и собственных серверов. Профили, подписки и списки никуда не передаются — они хранятся только в папке программы. Utgard не предоставляет VPN-серверы.

Сама программа обращается в сеть только в следующих случаях:

| Куда | Когда | Зачем |
|---|---|---|
| `github.com` | при запуске (отключается в настройках) и по кнопке «Проверить обновления» | узнать номер последней версии Utgard |
| `github.com` | при первом запуске, после вашего согласия | скачать sing-box 1.14.1 |
| адрес вашей подписки | при добавлении подписки и при её автообновлении | получить профили |
| ваши VPN-серверы | при запуске, при изменении списка профилей и по кнопке «ping до сервера» | измерить задержку |
| системный DNS | если указана папка zapret: при запуске, при изменении профилей и по кнопке «Исправить конфликт VPN и zapret» | узнать IP-адреса ваших серверов, чтобы проверить исключения zapret |
| `raw.githubusercontent.com` (репозиторий Flowseal/zapret-discord-youtube) | только по кнопкам обновления IPSet и проверки hosts на странице zapret | получить актуальные списки zapret |

Запросы к GitHub и к адресу подписки отправляются с заголовком `User-Agent: utgard/1.0`: получатель видит ваш IP-адрес и то, что запрос сделан Utgard.

Когда VPN включён, сетевые соединения устанавливает `sing-box`: к вашим VPN-серверам и к выбранному в настройках DNS-over-HTTPS (Google, Cloudflare или Quad9) для разрешения имён сайтов, которые идут через VPN.

## Требования

- Windows 10 x64 или Windows 11 x64;
- VPN-профиль или конфигурационная ссылка.

Дополнительный VPN-клиент устанавливать не требуется.

## Лицензия

Utgard Client распространяется под лицензией **MIT**. Полный текст лицензии находится в файле `LICENSE`.

### Сторонние компоненты

Utgard использует сторонние компоненты с собственными лицензиями.

В исходный код включена библиотека **Parson 1.5.4** для работы с JSON. Parson распространяется под лицензией **MIT**.

Файлы библиотеки находятся в каталоге:

```text
vendor/parson/
```

В `parson.c` и `parson.h` сохранено оригинальное уведомление об авторских правах и текст лицензии. При распространении исходного кода это уведомление необходимо сохранять в соответствии с условиями MIT.

Тексты лицензий распространяются вместе с программой в папке `licenses\`: лицензия Utgard, лицензия Parson (библиотека входит в `utgard.exe`) и перечень сторонних компонентов.

Utgard также использует `sing-box 1.14.1`, который распространяется под лицензией **GPL-3.0-or-later**. `sing-box` не входит в архив Utgard: программа скачивает официальный релиз с GitHub и запускает его как отдельную программу, не встраивая в `utgard.exe`. Файл лицензии из официального архива распаковывается рядом с `sing-box.exe`. Исходный код: https://github.com/SagerNet/sing-box/tree/v1.14.1
